# FLUX

***FLUX*** is a multiplayer, physics-driven, procedurally generated crafting and survival sandbox inspired by Minecraft, but built around physics and emergent interactions. I wanted to make something that doesn't just copy Minecraft 1:1, but its core sandbox principles are simply really good. So FLUX takes some of those ideas and pushes them in a more physics-driven direction, because.... idk. I really like to enjoy physics. This decision (wich lowk is the whole game) is gonna bring me so much pain 😭🙏.

You can find the current [GDD](https://docs.google.com/document/d/11Ip6rSM0H4UV5j_N1TI8Ph-VdHjWmD1HTLgHJ_OqXRI/edit?tab=t.0) here, or a potentially outdated version in `/docs/FLUX GDD.md`.
